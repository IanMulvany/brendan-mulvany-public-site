# Skip Images

List image keys (one per line) that should be excluded from the static site build.
These images will not have pages generated and will be excluded from navigation.

Lines starting with `#` are treated as comments.
Blank lines are ignored.

## Format

```
# Comment explaining why image is skipped
image_key_1
image_key_2
```

## Example

```
# Test images from scanning calibration
bm_2024_test_001
bm_2024_test_002

# Damaged negatives
roll_15_frame_22
```
